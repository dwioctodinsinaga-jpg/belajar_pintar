📚 1. Apa Itu Barisan Bilangan?

Barisan bilangan adalah susunan bilangan yang memiliki pola atau aturan tertentu.

Contoh:
2, 4, 6, 8, 10, ...

Polanya adalah bertambah 2.

📘 2. Barisan Aritmetika

Barisan aritmetika adalah barisan yang memiliki selisih tetap.

Rumus suku ke-n:

Un = a + (n - 1)b

a = suku pertama
b = beda
n = urutan suku
Contoh:

3, 6, 9, 12, 15, ...

a = 3 dan b = 3

U5 = 3 + (5 - 1) × 3

U5 = 15

📗 3. Barisan Geometri

Barisan geometri adalah barisan yang memiliki rasio tetap.

Rumus suku ke-n:

Un = a × r(n-1)

a = suku pertama
r = rasio
n = urutan suku
Contoh:

2, 4, 8, 16, 32, ...

a = 2 dan r = 2

U5 = 2 × 24

U5 = 32

📙 4. Deret Aritmetika

Deret adalah penjumlahan suku-suku dalam suatu barisan.

Rumus jumlah n suku:

Sn = n/2 (2a + (n-1)b)

📕 5. Deret Geometri

Rumus jumlah n suku (r ≠ 1):

Sn = a(rn - 1)/(r - 1)
